## Velora OS v0.1.0

### Что нового
- Загрузка через UEFI с помощью Limine 12.11.1 (протокол Limine, base revision 6).
- Вывод в последовательный порт COM1 и текстовая консоль на framebuffer: шрифт Spleen 8x16 с латиницей и кириллицей, ANSI-цвета, перемещение курсора.
- Своя GDT с TSS и отдельными стеками для double fault, NMI и machine check. IDT на все 256 векторов.
- Отчёт об исключении процессора: тип, код ошибки, причина page fault, регистры, CR0–CR4, стек вызовов.
- Отчёт о панике: сообщение, место в коде, регистры, стек вызовов.
- Сборка одной командой `./build.sh` в Linux и Windows. Свои инструменты: сборщик ISO (ISO 9660 + El Torito UEFI) и генератор FAT16 с длинными именами.
- Тесты: 15 юнит-тестов на хосте, 16 тестов ядра в QEMU и проверка паники, тест загрузки. CI на GitHub Actions.

### Исправления
- Нет (первая версия).

### Известные проблемы
- Только UEFI; загрузка через BIOS не поддерживается.
- ISO загружается как CD/DVD. Записанный на USB-накопитель образ не загрузится: гибридный образ пока не поддерживается.
- Консоль работает только с framebuffer 32 бит на пиксель.
- Прокрутка на реальном железе медленная (чтение из видеопамяти). Исправление — на этапе 2.
- Адреса в стеке вызовов не переводятся в имена функций.
- Прерывания и ввод с клавиатуры ещё не включены. Системой пока нельзя пользоваться: нет управления памятью, процессов и оболочки (этапы 2–8).

### What's new
- UEFI boot through Limine 12.11.1 (Limine protocol, base revision 6).
- Output to the COM1 serial port and a framebuffer text console: Spleen 8x16 font with Latin and Cyrillic, ANSI colours, cursor movement.
- Own GDT with a TSS and separate stacks for double fault, NMI and machine check. IDT for all 256 vectors.
- CPU exception report: type, error code, page fault cause, registers, CR0–CR4, backtrace.
- Panic report: message, source location, registers, backtrace.
- One-command build with `./build.sh` on Linux and Windows. Own tools: ISO builder (ISO 9660 + El Torito UEFI) and FAT16 image builder with long file names.
- Tests: 15 host unit tests, 16 kernel tests in QEMU plus a panic check, a boot test. CI on GitHub Actions.

### Fixes
- None (first release).

### Known issues
- UEFI only; BIOS boot is not supported.
- The ISO boots as a CD/DVD. Written to a USB drive it will not boot: hybrid images are not supported yet.
- The console only works with 32 bits-per-pixel framebuffers.
- Scrolling is slow on real hardware (reads from video memory). Fix planned for stage 2.
- Backtrace addresses are not resolved to function names.
- Interrupts and keyboard input are not enabled yet. The system is not usable yet: no memory management, processes or shell (stages 2-8).
