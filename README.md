# Velora OS

Операционная система для x86_64, написанная с нуля: своё ядро, свои драйверы,
своё пользовательское окружение. Разработка идёт по этапам, см. issues.

An x86_64 operating system written from scratch: own kernel, drivers and
userland. Development goes stage by stage, see the issues.
